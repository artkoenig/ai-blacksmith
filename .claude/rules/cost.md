# cost

The cheapest mechanism that does the job wins.

- A dispatch is the unit of cost, not a line of code. Every agent re-pays a system prompt, the
  CLAUDE.md hierarchy and the project rules before it does anything - a five-figure bill for
  `git checkout -b`.
- Before adding one, name the alternatives and why they lose: the caller doing it, a wrapper
  command, a script, or a step folded into an agent that already runs. Where none loses, say so.
- The same question at every step of a design: what does this cost, and what is the version that
  costs less? A structure nobody priced is one nobody can defend.
- Frugality is measured, not asserted. `forge-context` breaks a run's start down by source,
  `/stats` reads tool calls and tokens per run out of `.forge/metrics.jsonl`.
